# Welcome to Betrayed

Betrayed is a multi-game and community Discord. Follow these steps to get set up.

## 1. Read the rules

Read the server rules before participating. The rules should live in a dedicated, read-only rules channel rather than inside the welcome message.

## 2. Set up your server profile

Use a recognizable server nickname or Discord server profile. If you are joining for a particular game, using your primary in-game name can help other members identify you.

## 3. Choose your interests and access

Use Discord onboarding or the designated role-selection channel to choose the games, notifications, and community areas you want to see.

If you are joining a guild, coalition, group, or raid that requires private access, follow the staff contact process instead of publicly sharing private information.

## 4. Join the community

Browse the Community Chat and RuneScape sections, introduce yourself, and join the conversations that interest you.

## 5. Need help?

Contact the staff team through the server's designated help or support channel. Do not send sensitive account information to Zors Bot or post it in a public channel.
